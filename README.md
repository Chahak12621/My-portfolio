As a **Machine Learning & AI Engineer** and **Creative Developer** (BS in Data Science from IIT Madras & B.Sc. in Computer Science from Barkatullah University), this portfolio showcases end-to-end full-stack applications, intelligent AI models, data analytics projects, and bespoke interactive web experiences.

## ✨ Key Features

- 🌌 **Interactive Canvas Particle System**: Procedurally rendered particle network in the hero section responsive to mouse interactions and window resizing.
- 🎬 **Cinematic GSAP & ScrollTrigger Animations**: Fluid staggered text reveals, scroll-driven entrance transitions, and dynamic SVG line-drawing timeline.
- 🧲 **Magnetic Cursor & Micro-Interactions**: Physics-inspired magnetic buttons, interactive hover ripples, and responsive custom cursor follower.
- 🌊 **Lenis Smooth Scrolling**: Ultra-smooth, inertia-driven page scrolling experience.
- 🏷️ **Dynamic Project Filter**: Interactive categorization for full-stack, machine learning, and AI projects with smooth animated transitions.
- 💎 **Glassmorphism & Forest Glow Theme**: Tailored deep-forest and emerald-tinted color palette with sleek blur backdrops and glowing accents.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays with clean typography and layout hierarchy.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Chahak12621/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.

### Build for Production

```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```

### Code Linting

```bash
npm run lint
```
